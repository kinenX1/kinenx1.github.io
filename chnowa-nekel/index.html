How to install on Android

  1. Tap Download for Android at the top of this page.
  2. Open the downloaded file ChnowaNekel.apk (from the notification or your Files app).
  3. If Android asks, allow Install unknown apps for your browser, then tap Install.
  4. If Play Protect warns you, tap More details → Install anyway. This happens because the app isn't on the Play Store yet.
📱 iPhone? iPhones can't install APK files. Use Open in browser instead and add it to your home screen from the Share menu.
